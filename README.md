# 哈佛大学短期交流项目页面

这是锐尔教育“哈佛大学短期交流项目”独立页面，可部署到例如 `school.ruieredu.cn/harvard`，再将该链接放入公众号文章的“阅读原文”或二维码。

## 当前已完成

- 手机端优先的哈佛大学短期交流项目页
- 校园实拍图、项目概览、三大方向、项目安排与报名流程模块
- 哈佛大学官网与校园信息页的外链
- 咨询表单：提交后生成发往 `info@ruieredu.org` 的项目咨询邮件草稿
- 项目日期、费用、住宿与具体行程保留为咨询获取，未编造未确认信息

## 上线前替换

1. 在 `index.html` 中补充项目日期、费用、住宿安排、完整行程和已授权案例。
2. 核验 `info@ruieredu.org` 是否仍为接收咨询的邮箱；如有企业微信，可改为企业微信咨询入口。
3. 确认证书/成绩评定单的发证主体与完整课程大纲，避免使用不一致表述。
4. 部署到启用 HTTPS 的域名后，用微信真机测试“阅读原文”、图片加载和邮件咨询按钮。
