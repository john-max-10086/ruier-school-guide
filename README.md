# 哈佛大学申请指南页面

这是锐尔教育“院校库”第一版的独立静态页面，可部署到例如 `school.ruieredu.cn/harvard`，再将该链接放入公众号文章的“阅读原文”或二维码。

## 当前已完成

- 手机端优先的哈佛大学介绍页
- 校园实拍图、院校概览、学术方向与申请规划模块
- 哈佛大学官网与校园信息页的外链
- 咨询表单：提交后生成发往 `info@ruieredu.org` 的邮件草稿
- 真实案例占位：未使用未授权的学生信息

## 上线前替换

1. 在 `index.html` 中替换校园图片、课程/项目信息和已授权案例。
2. 核验 `info@ruieredu.org` 是否仍为接收咨询的邮箱；如有企业微信，可改为企业微信咨询入口。
3. 核对目标学院和项目的当年申请要求、截止日期和招生政策。
4. 部署到启用 HTTPS 的域名后，用微信真机测试“阅读原文”、图片加载和邮件咨询按钮。
